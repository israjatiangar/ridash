am moving haphazardly, doing Ts project then doing basic html css. But not
having something to do really bothers m, and i have ony one project showcasing

my Grid and Flexbox layouts. And showcasing my css skills, as i think just 1
project with html and css is not enough! This is also meant to show my design
aesthetics.
